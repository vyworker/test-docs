📦 [Название Аддона] для Blender

[Название Аддона] — это мощный инструмент для Blender, предназначенный для [кратко опишите главную суть: например, автоматизации репотопологии / генерации материалов / ускорения моделирования].

⚡ Быстрый старт

  1. Выберите объект в 3D Viewport.
  2. Нажмите Shift + A $\rightarrow$ меню [Имя аддона].
  3. Выберите нужный пресет или нажмите кнопку [Главная функция] на панели управления.

🛠️ Установка

Требования

Аддон протестирован и стабильно работает в Blender 4.0 и более новых версиях.

Инструкция по шагам:

  1. Скачайте последний релиз в формате .zip со страницы Releases.
  2. Откройте Blender и перейдите в Edit $\rightarrow$ Preferences... $\rightarrow$ Add-ons.
  3. Нажмите кнопку Install... в верхнем правом углу.
  4. Выберите скачанный .zip архив.
  5. Отметьте галочкой чекбокс напротив [Название Аддона], чтобы активировать его.

🖥️ Интерфейс и Панели

После активации аддон создает новую вкладку на боковой панели N-Panel в окно 3D Viewport.

💡 Как открыть N-Panel? Нажмите клавишу N на клавиатуре, находясь мышью в окне 3D Viewport.

Обзор боковой панели (N > [Имя Вкладки])

Панель / Секция Описание Основные функции
Main Operations Главные инструменты для работы с объектом Run Process, Reset Settings
Settings Тонкая настройка параметров и пороговых значений Tolerance, Iterations
Export Быстрый экспорт готового результата Export FBX, Bake Textures

⌨️ Горячие клавиши (Hotkeys)

Аддон регистрирует следующие сочетания клавиш по умолчанию:

  • Shift + Alt + Q — Вызов быстрого пи-меню (Pie Menu) в 3D Viewport.
  • Ctrl + Shift + X — Быстрое выполнение [Главной функции].

Кастомизация

Вы всегда можете изменить горячие клавиши под себя в настройках Blender:
Preferences $\rightarrow$ Keymap $\rightarrow$ поиск по имени "Имя Аддона".

❓ Частые вопросы (FAQ)

??? question "Что делать, если аддон выдает ошибку в консоли?" Убедитесь, что вы используете поддерживаемую версию Blender (4.0+). Если ошибка повторяется, откройте системную консоль (Window $\rightarrow$ Toggle System Console), скопируйте текст ошибки и создайте Issue в нашем GitHub репозитории.

??? question "Работает ли аддон в режиме редактирования (Edit Mode)?" Да, большинство функций автоматически определяют текущий режим (Object Mode или Edit Mode) и подстраивают алгоритм работы.
